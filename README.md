# LeapR

Windows 上离线看 TXT 的极简阅读器。默认窗口完全透明——屏幕上只看得见小说文字，
没有边框、没有标题栏、没有底板。

章节之间是**连续衔接**的：一直往下滚就能读完整本书，不会在章末出现翻页跳变；
内存里只保留当前章前后各几章。

改造自 Gitee 开源项目 `fish_read_windows`（PySide6），保留了它的分章 / 编码识别 /
老板键思路，重写了界面层，去掉了 EPUB/MOBI/PDF 分支，并新增外部字体加载。

## 启动

**方式一（推荐）**：双击桌面上的「LeapR」快捷方式。

**方式二**：双击项目里的 `启动.bat`。

**方式三（排查问题用）**：控制台启动，能直接看到报错

```
.venv\Scripts\python.exe main.py
```

启动后右下角通知区会出现托盘图标，并弹一次气泡提示——用来确认程序确实跑起来了。

### 打包成独立 exe

```
.venv\Scripts\python.exe tools\build_exe.py         # 产出 dist/LeapR/LeapR.exe
.venv\Scripts\python.exe tools\install_shortcut.py  # 在桌面创建「LeapR」快捷方式
```

产物不依赖 Python 环境，整个 `dist/LeapR` 文件夹拷到哪都能跑。

## 显示逻辑（鼠标驱动）

- **鼠标在窗口范围内**：窗口正常显示
- **鼠标移开**：整个窗口淡出，默认完全透明，屏幕上不留任何痕迹
- **鼠标移到窗口顶部那一带**：边框栏（书名·章节 + 操作按钮）自动浮现，移开就收起
- **鼠标靠近窗口边缘**：光标变成缩放箭头，可以像普通窗口一样拖拽调整大小，正文自动重排

找回窗口的三个入口：

1. 鼠标扫过窗口原来的位置（窗口还在，只是透明）
2. 托盘图标双击（通知区；找不到就点 `^` 展开，把图标拖出来固定）
3. `Esc` 或老板键 `Ctrl+Shift+X`

这几个开关在「阅读设置 → 窗口」：

| 开关 | 默认 | 作用 |
|---|---|---|
| 显示标题栏 | 开 | 允许鼠标悬停唤出顶部边框栏 |
| 显示窗口边框 | 开 | 鼠标靠近时描一圈淡轮廓 |
| 显示托盘图标 | 开 | 通知区图标，双击显隐，右键有菜单 |
| 启动时提示 | 开 | 启动弹一次托盘气泡 |

### 字号与字色

- 边框栏上的 `A-` / `A+` 直接调字号；`Ctrl+滚轮` 也可以
- 字体颜色、字号、行高、段距、字间距在「阅读设置 → 文字」里

## 快捷键

| 操作 | 说明 |
|---|---|
| 鼠标移入窗口 | 顶部浮出工具条，移开自动淡出 |
| `Ctrl+O` | 打开 TXT（也可以直接把文件拖进窗口） |
| `Ctrl+J` | 章节目录（左侧抽屉） |
| `Ctrl+,` | 阅读设置 |
| `←` / `→` | 上一章 / 下一章 |
| `↑` / `↓`、滚轮 | 滚动正文 |
| `Ctrl+滚轮` | 调整字号 |
| `Esc` 或 `Ctrl+Shift+X` | 隐藏窗口（老板键，再按一次回来） |
| `Alt+左键` 拖动 / 拖工具条空白处 | 移动窗口 |
| 拖拽窗口边缘 | 调整大小 |
| 右键 | 打开菜单（含最近打开、退出） |

## 背景三种模式

在「阅读设置 → 背景」里切换：

- **全透明**：什么都不画，只有文字。可额外勾选「文字衬底」垫一层极淡的底
- **纯色**：填充指定颜色，可调不透明度
- **图片**：选一张图作底，可调不透明度和底色叠加

## 字体

- 字体下拉里列出系统已安装的字体，中文友好字体排在前面
- 点「加载字体文件」可直接选 `.ttf` / `.otf`，注册进程序即可用，不需要装到系统里
- 已加载的字体文件路径记在 `config/settings.json` 的 `font_files`，下次启动自动恢复

## 配置与数据

- `config/settings.json`：所有设置
- `config/bookmarks.json`：阅读进度与最近书目

## 开发

```
.venv\Scripts\python.exe tools\selftest.py      # 分章 / 编码 / 字体 自测
.venv\Scripts\python.exe tools\screenshot.py    # 渲染截图到 tools/shots/
```

`books/` 里放了几份测试素材：有章节的短篇、无章节的片段、GBK 编码的文件。
